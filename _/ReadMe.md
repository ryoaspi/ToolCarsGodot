`_` is a folder for the integrators.   
The developer responsible for taking everyone’s code and making it work together.   
In a consistent, usable demo.   

Keep in mind that you are building a toolbox.     
Not a project.   

Another developer should be able to install Godox XR Tool and then run:  

```bash
git clone https://github.com/ryoaspi/ToolCarsGodot.git addons/ToolCarsGodot
```
After that, everything should be usable with simple drag-and-drop setup.
